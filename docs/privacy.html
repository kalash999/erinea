最終更新：2026年10月27日 ／ 対象：エリネアの個人利用・ローカル処理構成

kalash999（エリネア運用者・個人。以下「運用者」）は、エリネアによる情報の取得・利用・保存について、次のとおり説明します。本アプリは利用者自身のWindows PCで動作します。運用者がメールを集める共用サーバーは設けていません。

取得する情報利用目的保存と保護通信と共有保持・削除お問い合わせ

1. 取得する情報と権限

Gmail連携は任意です。利用者がGoogleの認証画面で許可したアカウントについて、gmail.readonly（メールの読み取り専用）の権限を使います。メールの送信、削除、ラベルの変更、既読・未読の変更は行いません。

  • メール情報：メールID、受信時刻、件名、差出人、テキストまたはHTMLから抽出した本文、読取できなかった本文部分の情報。
  • 取得時の原データ：Gmail APIの応答を保存するため、宛先などのヘッダー、ラベル、スレッドID、抜粋、MIME構造、添付ファイルの情報や応答に含まれるデータも保存される場合があります。会話用に選択した項目だけが原データに保存されるわけではありません。
  • アカウント・同期情報：接続先のメールアドレス、アカウント照合用のハッシュ、変更履歴ID、取得済みの位置、確認時刻など。別のアカウントへの意図しない切り替えや重複取得を防ぐために使用します。
  • 認証情報：OAuthクライアント情報、アクセストークン、更新トークン。Googleアカウントのパスワードをエリネアが受け取る仕組みではありません。
  • 利用者が指定した情報：対応ファイルの本文・画像から得た情報、ファイル名・保存場所・更新日時など、入力した会話や設定、処理結果・診断記録。

Gmailの取得は最近のメールを優先し、その後に過去のメールも順次読み取ります。受信トレイや新着メールだけに限定する設定ではありません。通常の添付ファイルを追加取得して本文解析する機能は対象外ですが、別取得になっているテキスト本文は取得します。

2. 利用目的とAI処理

取得した情報は、利用者本人に向けた資料の整理・検索、記憶の作成、要約、関連情報を横断した推測、質問への応答、記録を参考にした話しかけ、および取得・処理状況の管理に使用します。これらは情報の表示・整理を支援する機能であり、推測の正しさを保証するものではありません。

本ページが対象とする構成では、保存資料とその記憶を扱うAI処理は同じPC上のモデルで行います。記憶の作成はデータや索引の保存であり、AIモデル自体の追加学習とは異なります。Google APIから取得した情報とその派生情報を、汎用AI・機械学習モデルの訓練、追加学習または改良には使用しません。

Google APIから取得した情報の利用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。広告配信、情報販売、信用力の判定、第三者による監視には使用しません。

3. 保存場所と保護方法

取得時の原データ、会話用に整形した資料、記憶・索引・推測、会話履歴、同期状態は、利用者の管理するPC上のアプリ用保存先などに保存します。利用者が保存先を共有ストレージに置いたり、バックアップ・同期ソフトを使ったりする場合は、その保存先やソフトでもデータが扱われます。

保存するOAuth認証情報は、Windowsのデータ保護機能（DPAPI）を使って暗号化します。メール本文、資料、記憶などをアプリが一律に暗号化する実装ではありません。別途ダウンロードした接続用JSONファイルも、この認証情報保存機能で自動的に暗号化されるわけではありません。Windowsのアクセス権、端末のロック、ディスク暗号化、バックアップ先の管理は利用者の環境に依存します。

Googleとの認証・メール取得はHTTPSで行います。ローカル資料に由来する情報には外部送信を制限する属性を引き継ぎ、対応するAI通信では同じPCの接続先だけを許可する制御を設けています。この制御は、利用者によるコピーやOS・別のソフトの通信まで防ぐものではありません。

4. 外部通信・第三者への共有

  • Google：認証・トークン更新・Gmail取得に必要なクライアント情報、認証情報、メールIDや検索・同期の指定をGoogleへ送信します。取得したメールを保存するための別の外部サーバーは設けていません。
  • Web検索・公開ページの閲覧：これらを使う場合は、検索語やアクセス先などを検索サービス・閲覧先に送信します。ローカル資料由来と判定された情報を外部へ送らない制御があります。利用者自身が入力した検索語にも、公開したくない情報を含めないでください。
  • この説明サイト：GitHub Pagesで公開します。サイト独自のアクセス解析、広告、Cookie設定、入力フォーム、外部フォントや追跡用スクリプトは設置しません。配信元GitHubはIPアドレス等のアクセス情報を処理する場合があります。詳しくはGitHubのプライバシーステートメントをご覧ください。エリネアのメールや記憶をこのサイトへ送る機能はありません。
  • お問い合わせ：GitHub Issuesに投稿された内容は、問い合わせへの回答や不具合の確認に使用します。投稿はGitHub上で処理・公開され、他の人も閲覧できます。メールアドレス、メール本文、個人資料、接続用JSONなどの秘密情報は投稿しないでください。この窓口では一般的な操作・削除手順のみをご案内します。

Google APIから取得した情報を、広告業者、データ販売業者、外部のAI学習サービスに提供・販売しません。利用者以外の人がメールを閲覧するための遠隔管理機能は設けていません。サポートのために特定のデータを共有する場合は、利用者が内容を確認して明示的に共有した範囲だけを扱います。

5. 保持期間・接続解除・データ削除

取得済みの資料や履歴は、後から参照できるよう保持します。Gmail由来のデータ全体に対し、一定日数で一括自動削除する仕組みはありません。重複した内容の保存を抑える処理は、保存済み情報の削除とは異なります。

  1. 新しい取得を止める：「サイトからの取り込み」でGmailの取得を停止し、変更を保存します。
  2. 保存した認証情報を消す：Gmailを選択し、「保存した認証情報を消去」を実行します。これは端末内の認証情報を消す操作です。
  3. Google側の許可を取り消す：Googleアカウントの接続管理でエリネアのアクセス権を削除します。Google側の解除と端末側の認証情報消去は別の操作です。
  4. 取得済みデータを削除する：原データ、整形済み資料、記憶・推測・索引、会話履歴、同期記録、バックアップに残るコピーを対象に、保存先を確認して削除する必要があります。現行版には、Gmail由来の全データをまとめて消す専用ボタンはありません。運用者が保存先と関連情報を確認し、必要な処理を停止したうえで削除します。手順の確認は下記窓口へご連絡ください。

Google上のメール削除、アプリの取得元登録の削除、認証の解除だけでは、保存済みのコピーや記憶は自動では消えません。端末に残るデータを削除してもGoogle上の元メールは削除されません。

6. 方針の変更

取得範囲や利用目的、保存・共有の方法を変更する場合は、このページと必要なアプリ内の説明を更新します。これまで説明していない目的にGoogle APIデータを利用する場合は、必要な説明と同意を得てから変更します。
